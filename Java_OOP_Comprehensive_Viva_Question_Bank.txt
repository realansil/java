A. Very Basic Java Viva
-----------------------
1. Q: What is Java?
   A: Java is an object-oriented, class-based programming language designed to be portable through the JVM.
2. Q: What is the entry point of a Java program?
   A: The main method: public static void main(String[] args).
3. Q: Why is main() static?
   A: The JVM can call it without first creating an object of the class.
4. Q: What is a class?
   A: A class is a blueprint containing data members and methods.
5. Q: What is an object?
   A: An object is an instance of a class.
6. Q: What does new do?
   A: It creates an object and allocates memory for it.
7. Q: What is a method?
   A: A method is a block of code that performs an operation.
8. Q: What is a variable?
   A: A named storage location for a value.
9. Q: What is a data type?
   A: It specifies the kind of value a variable can store.
10. Q: Name Java primitive data types.
   A: byte, short, int, long, float, double, char and boolean.
11. Q: What is a reference type?
   A: A type that refers to an object, such as a class, array or interface reference.
12. Q: What is Scanner used for?
   A: It is commonly used to read input from the keyboard.
13. Q: Why is java.util.Scanner imported?
   A: Scanner belongs to java.util.
14. Q: What does System.in represent?
   A: The standard input stream, normally the keyboard.
15. Q: What does System.out represent?
   A: The standard output stream.
16. Q: What does sc.nextInt() do?
   A: It reads an integer.
17. Q: What does sc.nextDouble() do?
   A: It reads a double.
18. Q: What does sc.nextLine() do?
   A: It reads the remaining line as a String.
19. Q: What does sc.next().charAt(0) do in prim.java?
   A: It reads a token and takes its first character.
20. Q: Why should Scanner be closed?
   A: To release the input resource when it is no longer needed.

   A: Converting a smaller compatible primitive type to a wider type, such as int to double.
23. Q: Is widening conversion explicit here?
   A: No. The assignment double num2 = num is implicit.
24. Q: What is narrowing conversion?
   A: Converting a wider primitive type to a narrower type, such as double to int.
25. Q: Why is (int) used before db?
   A: Because narrowing conversion requires an explicit cast.
26. Q: What happens to the decimal part when double is cast to int?
   A: The fractional part is discarded.
27. Q: What is char?

28. Q: Why is num2 declared as double?
   A: To demonstrate widening conversion from int to double.
29. Q: Why is db2 declared as int?
   A: To demonstrate narrowing conversion from double to int.
30. Q: Is prim.java mainly an OOP program?
   A: No. It mainly demonstrates Java fundamentals and type conversion.
